# Changelog

## 0.1.0

- Scaffold the dedicated game repository from `mg-platform` (`v4.1.0`).
- Five-lane real-time battle with shield, archer, ram and healer sheep.
- Player vs AI with easy/normal/hard seeded opponent.
- Shared-screen two-player mode with a 180° rotated top rail and red units.
- No time limit: base destruction ends the match; 60-second pressure phases
  guarantee resolution.
- Fixed-step simulation, interpolated rendering, queued input, pause on blur
  with 3-2-1 resume countdown.
- Procedural sheep art and SVG app icon; zero external runtime requests.
- 11-language UI, versioned profile save, match statistics.
- Rules, AI, determinism and responsive-layout tests.
